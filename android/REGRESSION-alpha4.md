# DengShell Android 0.1.0-alpha4 回归记录

日期：2026-09-25。实机：MEIZU 21，Android 16，ARM64。测试使用隔离的本机 SSH/SFTP 服务，并通过 USB 连接手机；没有访问用户的正式服务器。测试配置、临时文件和端口映射已清理，手机上保留 alpha4 应用。

## 结果

| 范围 | 结果 |
| --- | --- |
| 安装和启动 | ARM64 APK 在实机安装、启动正常；连续升级 alpha2 → alpha3 → alpha4 后，测试配置仍可使用。后台切走再返回，SSH 会话仍在。 |
| SSH 连接 | 密码与独立测试私钥认证、首次及变化后的主机指纹确认、会话建立、断开和重新连接通过。两种认证下终端执行回声命令并收到预期输出。Android 系统选择器读取测试私钥并保存为应用密钥也已实测。 |
| 终端输入 | 竖屏软键盘弹出后，终端左边界和命令栏仍在可视区域；终端无横向滚动偏移。 |
| SFTP | 列表、上传、下载、改名、删除通过；上传/下载文件与原文件的 SHA-256 一致。系统文件选择器可打开。最终 alpha4 实机保存了 `.txt`、未知扩展名和 16 MiB 文件，文件名与内容均正确；取消系统保存窗口后，已有文件未改变。大文件须等待写入完成后再校验。 |
| 远程监控 | CPU、内存、网络、进程和磁盘数据正常刷新；竖屏向下滚动能到达磁盘区域。独立 API 探测连续 6 次返回成功。 |
| 对话框和返回键 | 返回键关闭重命名弹窗后，再次打开仍正常；取消删除后文件仍在。 |
| 排版和触控 | 实机竖屏、横屏主要页面可用；浏览器在 390×844 和 844×390 下各通过 22 项，共 44/44，无脚本错误或页面横向溢出。覆盖导航、抽屉、表单滚动、私钥文件读取、系统上传入口和设置菜单。 |
| 远程编辑与覆盖保护 | 独立移动浏览器连接隔离 SSH 服务，15/15 项通过：文本保存成功；并发改动返回 409，远端内容与未保存草稿均保留；取消重新读取仍保留草稿。多文件上传中的新文件正常完成，同名文件须确认后才覆盖，取消覆盖不改原文件。 |
| 后端与安装包 | `go test ./internal/... -count=1` 通过；五种 APK 均构建成功、签名校验通过，所含 CPU 架构正确，SHA-256 校验通过。Android lint 无错误；实机日志未发现应用崩溃。 |

## 此轮修复

- 修复竖屏键盘弹出后终端左侧内容被裁切的问题。
- 调整移动端命令栏高度，命令提交失败时保留输入。
- 修复下载文件名错误地变成 `.bin` 的问题。
- 修复按返回键关闭确认框后，后续确认框无法打开的问题。
- 调整移动端抽屉、文件选择器和不适用于 Android 的桌面操作。

## 仍需继续验证

- 32 位 ARM、x86、x86_64 包已完成构建、架构和签名核对，但没有对应实体设备的运行记录。
- 更多 Android 版本和不同 SSH 服务器仍需兼容性测试。
- 大文件上传中途取消、真实网络断线与覆盖冲突、进程被系统终止后的恢复尚未完成实机验证。
- 横屏下若使用浮动输入法，输入法窗口可能覆盖应用的一部分。这由输入法的位置决定，可切换到停靠键盘。
- 当前提供调试签名的 alpha APK；Android 自动安装更新未接入，正式发布需使用稳定的发布签名并补充升级测试。
