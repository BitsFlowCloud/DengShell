# Remote operating-system identification marks

These small, locally bundled SVGs identify the operating system reported by an SSH server. They do not brand DengShell and do not imply sponsorship, certification or endorsement by any distribution or trademark owner. No network requests are made to these sources at runtime.

The SVG files are unchanged upstream originals (including their monochrome palettes); only their display size is reduced, with a light surrounding surface for contrast in either application theme. AlmaLinux uses its official full-colour icon. Exact upstream URLs, revisions, original brand sources, guidelines and SHA-256 digests are recorded in `sources.json`.

- **Rocky Linux**: Rocky Enterprise Software Foundation and artwork contributors. [Original artwork repository](https://github.com/rocky-linux/branding), CC BY-SA 4.0; see `LICENSE-ROCKY-CC-BY-SA-4.0.txt`.
- **Fedora**: Fedora Project / Red Hat, Inc.; [brand guidelines](https://docs.fedoraproject.org/en-US/project/brand/) and [trademark guidelines](https://fedoraproject.org/wiki/Legal:Trademark_guidelines) apply. This original monochrome identification mark is not a DengShell brand asset.
