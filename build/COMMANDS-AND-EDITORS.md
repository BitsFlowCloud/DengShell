# 命令与多文件编辑器

## SSH 终端输入

在 Shell 提示符下，直接向终端粘贴多行命令会自动执行到最后一行，无需再按回车；支持 Ctrl+Shift+V、右键粘贴及系统产生的粘贴事件。heredoc 的正文和结束标记按原文传入。单行命令仍可先编辑再按回车，终端底部输入条和命令编辑区仍按各自的发送方式操作。

Ctrl+C 中断当前终端中的命令，同时滚动到屏幕底部；其他 SSH 标签的滚动位置保持不变。Ctrl+Shift+C 复制选中文字。

## 命令与分组

下方面板进入“命令”。命令分组可以拖动排序；命令可以在列表中排序，也可以拖到其他分组。右键命令提供编辑、调用前编辑、删除及向前／向后移动；右键分组可以重命名。

每条命令独立保存“末尾添加回车 CR”。新建及没有该字段的旧命令默认不勾选：点击后只填入终端，继续补充参数，最后自行按回车。勾选后点击会执行。终端底部原输入条仍为 Enter 发送并执行、Shift+Enter 换行；需要预览和回车控制时，点击输入条旁的编辑图标。

不加回车时删除末尾换行；多行命令需要终端开启括号粘贴，否则保留在编辑区，不发送。不要将“不加回车”理解为对任意远程 TUI 的沙箱：终端应处于准备输入命令的提示符，远程程序依其自身规则处理收到的文字。

## 参数与反复调用

编辑命令时点击“参数1”至“参数5”，在光标处插入 `[p#1 参数名]` 等占位符。可以修改参数名，同一个编号出现多次时使用同一个值。

例如：`docker logs [p#1 容器] --tail [p#2 行数]`。调用时填写 `web` 和 `50`，预览为 `docker logs web --tail 50`。参数按文本原样替换，不执行模板表达式，也不自动添加 Shell 引号；空格和引号请在预览中核对。

命令编辑区的目标服务器单独显示。切换顶部 SSH 标签不会更换目标，需要时在“发送目标”中明确选择。原会话断开、关闭或转移时不能发送，不自动借用重连后或其他窗口中的会话。

命令和参数在本次运行中保留，便于修改后反复调用；运行时参数不自动保存到快捷命令模板。要永久保存命令模板，选择“存为快捷命令”。Ctrl+Enter 按当前回车选项发送。

## 文本标签和窗口

双击文件即可打开，每个文件拥有独立标签。标签及标题标注所属服务器和文件名，“当前查看”表示该编辑窗口当前的文件，星号表示未保存。不同服务器的同名、同路径文件分别管理。

“移到新窗口”把当前文件移至另一个可拖动、可调整大小的应用内编辑窗口；每个窗口有自己的标签栏。“合并到另一窗口”移回其他编辑窗口。上限为 12 个编辑窗口、40 个文件。

文本内容、编码、选区、滚动位置和撤销记录分别保留。Ctrl+S 保存当前文件，Ctrl+Tab / Ctrl+Shift+Tab 切换本窗口文件，Ctrl+W 关闭当前文件。关闭未保存文件会询问；“收起”只隐藏窗口，文件工具栏“文本编辑器”可恢复。

保存始终指向文件原所属的 SSH 会话和路径；远程变化冲突时停止覆盖。断线后内容继续保留供复制；请从重新建立的连接打开文件，核对新内容后再粘贴、保存。草稿当前只保存在内存中，退出前需要保存或复制。

### 当前文件搜索与定位

文本编辑器中，Ctrl+F 搜索、Ctrl+H 替换、Ctrl+G 定位行，F3 / Shift+F3 查找下一个 / 上一个。搜索按普通文本匹配，可区分大小写；“全部替换”只作用于当前标签，可用 Ctrl+Z 撤销。每个标签独立保留搜索词和替换内容，移动至其他窗口后保持不变。Esc 先关闭搜索或定位栏。

顶部保留一行文件标签及常用操作；编码、重新读取、复制全文位于“更多”，拆分和合并位于“窗口”。完整路径和状态在底部显示，悬停可查看完整信息。
