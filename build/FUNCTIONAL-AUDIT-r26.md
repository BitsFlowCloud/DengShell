# DengShell R26 功能审查

审查日期：2026-09-14。目标构建号：`20260914026`。以 R20 以来全部改动为回归范围，重点复核本轮命令管理、FinalShell 导入和多文件编辑。

## 本轮确认并处理的问题

| 问题 | 修复和防护 |
| --- | --- |
| 快捷命令固定追加回车，无法先补参数 | 每条命令独立保存回车选项，默认关闭；末尾换行规范化；无括号粘贴时拒绝发送不执行模式下的多行内容 |
| 模板参数可能未填写就进入终端 | 1–5 号参数在本地替换，提供预览，未填写或占位符无效时不发送；不执行模板表达式 |
| 修改参数时切换服务器可能误发 | 编辑区明确显示并保留原目标会话；关闭、重连或转移后不自动借用其他连接 |
| 命令和分组没有排序入口 | 拖动排序及跨组移动，右键提供前后移动；锁内只修改位置，保留其他窗口已编辑的命令内容 |
| 保存排序时失败导致界面与配置不一致 | 写入失败回滚；目标已删除时拒绝移动并提示刷新；配置重开后顺序保持 |
| 常驻编辑按钮占用快捷命令空间 | 编辑、删除、调用前编辑统一放入右键菜单，保留键盘菜单入口 |
| 单文本编辑器打开新文件会替换原文件 | 每文件独立标签、文本模型和网络请求；多个编辑窗口各有自己的标签栏 |
| 跨服务器同路径文件容易混淆 | 以会话 ID 与路径联合区分，标题／标签／内容区标注服务器；保存绑定原目标和版本校验值 |
| 读取、编码切换的迟到响应覆盖新编辑 | 独立读取代次，丢弃失效响应；解码失败保留原内容、撤销记录与可编辑状态 |
| 保存中继续输入导致新文字丢失 | 保存只推进已确认的基线和哈希，不覆盖当前文本模型；新输入继续标为未保存 |
| 关闭、断线和剪贴板异步操作丢失内容 | 关闭未保存文件提示、保存中禁止关闭；断线保留草稿供复制；异步粘贴检查文件和模型身份；剪切保留原换行 |
| 发行脚本可能携带旧 Linux 兼容验证结论 | 兼容报告必须匹配本次可执行文件 SHA-256；允许明确指定本次构建记录，新增 Arch 原生 makepkg 包 |
| 新字体授权说明未出现在外置发行许可目录 | 安装与绿色包额外携带五套界面字体 OFL 全文，程序内离线许可继续保留 |
| 编辑器焦点在工具栏时 Ctrl+S 落入浏览器默认操作 | 保存快捷键覆盖整个编辑窗口，同时避免文本区重复提交 |
| 手册仍称点击快捷命令一定执行、使用旁边编辑按钮 | 更新程序内手册、功能引导、GitHub 说明及累计更新日志，与新操作一致 |

## 边界

“通过”仅指上述实际运行或检查的范围。36 项跳过测试没有计为通过。本次未在真实 Windows 上执行 R26 安装／卸载；此前用户使用旧版正常不能替代本版实机回归。

Linux 容器采用 Xvfb／软件渲染。实体显卡、Wayland、托盘服务及任意 DPI 组合未穷尽；容器专用的 WebKit 沙箱／渲染覆盖不进入发行启动器。Arch 衍生发行版还取决于其实际仓库和运行库版本。

编辑窗口是同一应用内的独立窗口与标签，文件草稿只保存在内存中。关闭应用前需要保存或复制；不声称支持崩溃后的草稿恢复。发送参数按文本原样替换，用户应检查目标、引号及最终命令内容。

国际测速脚本沿用原约定，本轮没有更换或执行。没有修改用户实际配置、SSH 私钥、自定义字体和背景；所有验证使用独立缓存目录或隔离容器。
