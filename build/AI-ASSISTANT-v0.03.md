# AI 助手 · v0.03 构建 20261010103

同步按钮右侧的 AI 入口打开独立助手窗口，不占用 SSH 工作区。桌面标题栏依次提供置顶、最小化、最大化/还原与关闭按钮，再次点击入口会唤回已有窗口。每个窗口默认关闭自动操作；启用后，模型可使用原工作区的 SSH 终端、按键、会话、SFTP、监控和视图工具。RDP 图形操作不在本次范围内。使用方法见 [README](../README.md#ai-助手)。

## 实现

- 长任务取消固定 24 轮模型请求 / 64 次工具操作上限；完成、手动停止或原有会话守卫结束运行。模型 API 自身的请求失败与 SSH 断线仍按现有机制报告，不自动重发修改命令。
- 重复 read_terminal 对同一运行会话按 5/10/20/30 秒退避，可显式观察至 60 秒；返回空闲提示符可提前结束。每 100 ms 检查停止与会话身份，输入、空闲提示符或新任务重置退避。
- 操作历史以完整 assistant/tool 交换为单位收拢，保留最新完整结果及厂商思考签名，历次用户要求以 user 角色完整保留。按 Go JSON 实际转义后的字节数为系统上下文和工具定义预留容量，避免无限增长跨过后端请求大小及消息数边界。

- AI 执行器与终端工具保留在原工作区，独立窗口只显示对话和提交受限操作。双向消息中继存于内存，有心跳、确认游标和大小限制；快照不携带密钥。关闭助手、原窗口退出、锁定或通信中断时停止后续操作。
- 桌面助手使用独立原生窗口进程与可拖动的自定义标题栏；启动凭据通过继承管道传递，不进入命令行或磁盘。置顶只作用于 AI 窗口，不保存或改变 SSH 主窗口尺寸。浏览器弹窗使用浏览器自身的窗口框架，不显示原生窗口控制按钮。
- 后端提供服务设置、模型发现、工具对话与显式取消接口。支持 OpenAI Chat Completions 兼容协议、Anthropic Messages、Gemini generateContent，并保留工具调用所需的原生思考签名。各服务的接口、密钥、模型与思考参数独立配置。
- 首次使用的配置列表为空，不预置厂商或凭据；可手动保存 0–24 组配置，同一接口的多个 Token 通过独立配置 ID 分别保存。已有用户配置保留。
- 每组配置独立选择系统代理、直连、HTTP 或 SOCKS5，模型发现使用当前草稿的代理，对话使用已保存配置的代理。每次请求创建独立传输并关闭闲置连接，不读取 SSH 代理选择，也不修改全局 HTTP 传输或环境变量；显式代理失败不回退直连。
- `dengshell.ai.enc` 使用现有本机配置密钥和独立认证域加密 Token 与 AI 代理密码，不进入普通配置导出或同步。接口变更不继承旧 Token，代理身份变更不继承旧密码；公开设置不返回凭据，跨来源 HTTP 重定向被拒绝。便携目录迁移保留加密文件及原密钥。
- 浏览器和原生桌面共用操作循环，原生 IPC 另用取消接口停止模型请求。停止、锁定、手动切换/关闭会话或窗口交接使迟到响应失效；空闲锁定无需界面轮询也会取消模型请求。
- 终端复用已连接的 PTY；普通命令须处于已确认的 Shell 提示符，交互程序使用文本输入和按键。工具返回观察结果，不编造命令退出码。跨会话操作须先明确选择目标。
- 文本文件按本轮读取的路径、编码与 SHA-256 保存；截断内容不可覆盖，外部修改导致冲突。远端输出、文件和名称被标记为不可信数据，工具日志继续作为纯文本显示。
- 模型回复使用 Markdown 排版：解析结果通过允许的 DOM 元素与文本节点构建，禁用原始 HTML，不加载远程图片；链接仅允许无账号信息的 HTTP(S) 地址，真实点击后通过原生外部浏览器接口打开。解析器缺失、超长或超深嵌套会完整回退到原文。
- 用户气泡居右、模型气泡居左；模型名称在开始执行本轮任务时固定。每条回复可切换原文与排版、复制原始 Markdown。较长原文保留在原工作区内存中，经受限消息中继分块读取；缓存随对话清空和安全锁清理，最大 16 MiB，移除后明确提示，不把预览冒充完整原文。
- 追加操作和结果只更新新增内容，保留已有回复节点、选区、表格和代码块的横向位置；用户上翻时不强制滚到底部。
- 助手窗口中的真实输入计入安全锁活动，后台轮询和模型进度不会延长闲置时间。终端观察计时避免形成后台嵌套计时链，防止隐藏窗口后读取结果长时间停滞。
