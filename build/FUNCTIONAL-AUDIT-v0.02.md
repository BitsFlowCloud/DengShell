# v0.02 功能检查范围

本次检查覆盖连接/分组/备注、SSH 终端、SFTP/编辑器/历史路径、监控与进程、安全锁、自建同步，以及安装和旧版升级。真实 SSH 与 SFTP 使用本机隔离容器和临时配置，未操作用户服务器或原始配置。

新增回归：连接永久删除与迟到 SFTP 返回竞争；备注每行宽度、输入法、多标签隔离、明暗模式与窄窗口；v0.01 R50 到 v0.02 的版本和包元数据迁移。

本地 Go 全套与前端回归、浏览器流程、竞态检测、实际 SSH/SFTP 场景作为发布前检查。Windows 原生安装/升级和 macOS 两种芯片运行由 GitHub Actions 验证；Linux DEB/RPM/pacman 在六个隔离发行环境安装、启动和卸载验证。最终结果与验证链接见 v0.02 的 GitHub 发布说明。

验证不等于所有系统、驱动、远程服务器和网络组合均不存在问题。Windows 原生验证使用 Server 2022/WebView2；Linux 使用容器与虚拟显示；macOS 仍为未公证预览版。RPM、通用 Linux 和 macOS 当前手动更新。
