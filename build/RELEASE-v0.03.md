# DengShell v0.03 · 构建 20261010103

本轮改善 Windows 与 Linux 的 AI 长任务执行：解除固定轮次和操作数上限，自动等待运行中的终端并收拢较早记录，保留用户要求、最新结果和随时停止能力。适用于下载、安装和系统升级等耗时任务。

版本仍为 v0.03；现有 Windows、DEB、pacman 客户端可通过内置更新获取本版，其他 Linux 格式重新下载安装。个人连接、密钥、字体及背景沿用原配置。官网 macOS、Android 保留此前下载版本。

此前 v0.03 的累计变化见 CHANGELOG.md。验证覆盖范围以本次发布验证记录为准。
