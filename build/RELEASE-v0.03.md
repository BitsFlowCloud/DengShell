# DengShell v0.03 · 构建 20261011105

本轮修复隐藏 SFTP 文件面板后终端没有铺满、留下空白的问题：隐藏后终端自动占满可用工作区，再次显示时恢复文件面板和分隔布局。同时发布此前已交付的文本编辑器自动折行改进，长行按窗口宽度显示，逻辑行号与正文同步；复制、保存、编码和原有换行保持不变。

版本仍为 v0.03；本次提供 Windows 安装版、绿色 ZIP、Linux DEB/RPM/pacman/通用包和源码。现有 Windows、DEB、pacman 客户端可通过内置更新获取本版，其他 Linux 格式重新下载安装。个人连接、密钥、字体及背景沿用原配置。官网 macOS、Android 保留此前下载版本。

R20 以来的累计功能和修复见 CHANGELOG.md，包括多会话 SSH/SFTP、独立窗口、服务器监控、文本编辑器、AI 长任务、安全锁、同步与签名更新。验证覆盖范围以本次发布验证记录为准。
