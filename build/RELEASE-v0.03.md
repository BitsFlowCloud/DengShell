# DengShell v0.03

## 2026-10-08 · 文本编辑器行号

- 修复 [#31](https://github.com/BitsFlowCloud/DengShell/issues/31)：文本编辑器左侧显示行号，与正文纵向滚动同步，横向滚动时保持可见。
- 编辑、粘贴、撤销重做、搜索替换和重新读取时同步更新行号；各文件标签与独立窗口分别显示。
- 兼容明暗主题、缩放和窄窗口；行号不进入复制或保存内容，保留原有编码与换行。

## 2026-10-03 · AI 助手与全平台更新

- 同步按钮右侧新增 AI 入口；桌面助手使用独立窗口，可置顶，不占用 SSH 工作区。启用后可自动读取终端、发送命令和交互按键、切换或连接已保存会话、读写远程文件，支持随时停止。
- 支持 OpenAI 兼容、Anthropic / Claude、Google Gemini 协议；可同时保存多组 Token，每组独立选择系统、直连、HTTP 或 SOCKS5 代理，与 SSH 代理完全分开。首次使用无厂商或凭据预设；Token 和代理密码本机加密，不回填、不随连接导出或同步。
- 对话支持 Markdown 表格、列表、粗体、引用和代码块；用户与模型左右气泡排列，每条回复标注本轮模型名称，提供完整原文查看及复制，保留符号与换行。
- 操作记录和顶部配置栏改为紧凑布局；进度刷新保留选区、阅读位置及表格横向滚动。修复 Linux 系统选择框文字裁切。
- Android 同步 AI 与共用修复，提供独立助手页面、系统返回和触控适配；沿用原签名，提高内部安装版本，覆盖升级保留配置。
- 保留 v0.03 的文件路径与非普通文件读取、目录切换竞态、SFTP 上传兼容、多实例安全锁、同步认证、命令草稿和延迟采样修复；Windows 继续使用 UPX 压缩。

## R20 至今累计功能与修复

- **SSH 工作区**：SSH 命令快速连接、密码/私钥/SSH Agent、多会话、独立窗口；标签与终端左边框对齐，每行最多六个，窄窗口自动换行。修复监控导致误断线、重连丢失终端内容及提示符重复。
- **服务器管理**：多级分组、颜色、搜索、多选、FinalShell 导入；再次点击当前分组可收起或展开。名称加粗、地址紧凑显示，备注独立成框且直接显示正文，最多三行、每行 20 个中文/40 个英文字符；保留旧长备注及完整查看。
- **文件与编辑器**：SFTP 上传下载、传输记录清理、历史路径搜索、按服务器隔离的常用目录收藏；多标签文本编辑支持搜索、替换和定位行，仅作用于当前标签。修复紧凑窗口工具栏重叠、迟到请求及编辑器竞态。
- **终端操作**：Ctrl+C 跟随到最新输出；直接粘贴多行命令到空闲终端时自动执行，支持 heredoc 和中文。参数化快捷命令发送成功后收起输入面板，保留再次编辑与失败重试。
- **终端显示与阅读**：连接进度在终端内显示；NQ 等脚本刷新与清屏时可保持上翻阅读位置。修复字符画真彩色、256 色、中文网格、跨行背景和复制内容，统一柔和近黑外观并恢复背景选择与强度调节。
- **磁盘统计**：已用、可用和总计空间汇总本地磁盘文件系统，包含独立挂载的 /home、/data；去除设备别名、重复挂载及子卷重复计数，保留读写速度。
- **监控与外观**：CPU/内存前五进程、完整进程页搜索排序分页、最近 60 秒网速和延迟、紧凑 IP 与磁盘空间/读写显示；独立界面/Shell 字体、在线字体库、背景和曲线自定义。修复非 100% 缩放时终端选择错行。
- **安全锁**：密码或 2FA、空闲自动锁定、主动锁定和多窗口隔离；修复聚焦检查闪现解锁框、关闭窗口确认消失及锁定状态无法退出。
- **自建加密同步**：本机、NAS 或 VPS 部署，无需域名，通过一次性邀请与证书身份配对；同步服务器、分组和快捷命令，可选密码及托管私钥。保留历史恢复、离线编辑、设备撤销；修复并发合并、失败重试、空间耗尽及锁定时请求取消等问题。
- **安装与更新**：Windows 系统代理、Linux GNOME/KDE 手动代理及代理环境变量；修复更新助手启动失败、临时目录残留和打包兼容性问题。更新继续验证发行签名、大小及 SHA-256。

## 下载与升级

- **Windows 10/11 x64**：安装版 EXE、绿色 ZIP，包含内置 RDP 标签页测试功能。
- **Linux x64**：DEB、RPM、pacman 和通用 tar.gz；Ubuntu 22.04 / glibc 2.35 构建基线，需要 GTK3 / WebKitGTK 4.1。
- **macOS 13+**：Apple 芯片与 Intel 通用 DMG / ZIP，临时签名、未公证预览版。
- **Android 7+**：0.3.0（versionCode 11），提供 ARM64、ARMv7、x86_64、x86 及通用 APK；原调试签名，支持覆盖安装，需保持系统 WebView 更新。
- **源码**：桌面、Android、构建与验证脚本、内置 RDP 补丁及许可证，不包含用户配置或签名私钥。

桌面显示 **v0.03**，构建 **20261008102**；Linux 包版本 **0.3.0-102**。Windows、Debian/Ubuntu 与 R28 起的 pacman 客户端可通过“检查更新”升级，继续校验签名、大小及 SHA-256。RPM、Linux 通用包、macOS 和 Android 请手动安装。

升级保留配置、密钥、字体和背景；请先保存正在编辑的文件，桌面更新会关闭连接会话。AI 默认关闭，启用后会把指令及操作所需内容发送至选定服务。关闭助手、锁定、手动切换会话会停止后续操作；已发送的远程命令可能仍需在终端按 Ctrl+C 中断。RDP 图形桌面暂不支持 AI 操作。
