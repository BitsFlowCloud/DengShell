# DengShell v0.03

## v0.03 · 2026-10-03

- 修复名为 `~` 的远程文件或目录被错误解析为主目录的问题，确保打开、改名、删除和传输操作使用正确路径。
- 下载和编辑前识别 FIFO、设备等非普通文件，避免文件通道卡住及失败时覆盖本地已有文件；普通文件和有效符号链接继续支持。
- 修复多个程序实例同时使用安全锁时旧状态覆盖新设置的问题；损坏、删除或密钥变化时拒绝覆盖，并阻止双因素验证码跨实例重复使用。
- 修复加密同步改变连接认证方式后，错误复用私钥口令或遗留旧私钥路径的问题。
- 修复快速切换目录、关闭或重建连接后，迟到的文件请求覆盖当前界面状态的问题。
- 文件通道关闭后正确显示不可用状态；兼容不提供 OpenSSH 原子覆盖扩展的 SFTP 服务上传新文件。
- 延迟采样按会话独立进行；窗口隐藏或锁定时停止发起采样，忽略已失效会话的返回结果。
- 命令发送被窗口交接、恢复或断线状态拒绝时保留输入草稿，仅在发送成功后清空。
- Windows 客户端使用 UPX 压缩，并保留更新器兼容处理；各平台统一升级至 v0.03，保留既有功能和用户配置。

## 最近版本保留的改进

- 快捷命令发送目标跟随当前 SSH 标签，参数草稿与手动目标保留，多参数横向排列并自动换行。
- 文件支持多选、批量删除、打包下载及复制路径；上传冲突集中确认，上传保持当前页面并通过未查看数量提醒完成结果。
- 连接卡片整块操作、会话标签拖动排序、紧凑连接表单，以及 CPU/内存/交换空间零占用显示修复。

## R20 至今累计功能与修复

- **SSH 工作区**：SSH 命令快速连接、密码/私钥/SSH Agent、多会话、独立窗口；标签与终端左边框对齐，每行最多六个，窄窗口自动换行。修复监控导致误断线、重连丢失终端内容及提示符重复。
- **服务器管理**：多级分组、颜色、搜索、多选、FinalShell 导入；再次点击当前分组可收起或展开。名称加粗、地址紧凑显示，备注独立成框且直接显示正文，最多三行、每行 20 个中文/40 个英文字符；保留旧长备注及完整查看。
- **文件与编辑器**：SFTP 上传下载、传输记录清理、历史路径搜索、按服务器隔离的常用目录收藏；多标签文本编辑支持搜索、替换和定位行，仅作用于当前标签。修复紧凑窗口工具栏重叠、迟到请求及编辑器竞态。
- **终端操作**：Ctrl+C 跟随到最新输出；直接粘贴多行命令到空闲终端时自动执行，支持 heredoc 和中文。参数化快捷命令发送成功后收起输入面板，保留再次编辑与失败重试。
- **终端显示与阅读**：连接进度在终端内显示；NQ 等脚本刷新与清屏时可保持上翻阅读位置。修复字符画真彩色、256 色、中文网格、跨行背景和复制内容，统一柔和近黑外观并恢复背景选择与强度调节。
- **磁盘统计**：已用、可用和总计空间汇总本地磁盘文件系统，包含独立挂载的 /home、/data；去除设备别名、重复挂载及子卷重复计数，保留读写速度。
- **监控与外观**：CPU/内存前五进程、完整进程页搜索排序分页、最近 60 秒网速和延迟、紧凑 IP 与磁盘空间/读写显示；独立界面/Shell 字体、在线字体库、背景和曲线自定义。修复非 100% 缩放时终端选择错行。
- **安全锁**：密码或 2FA、空闲自动锁定、主动锁定和多窗口隔离；修复聚焦检查闪现解锁框、关闭窗口确认消失及锁定状态无法退出。
- **自建加密同步**：本机、NAS 或 VPS 部署，无需域名，通过一次性邀请与证书身份配对；同步服务器、分组和快捷命令，可选密码及托管私钥。保留历史恢复、离线编辑、设备撤销；修复并发合并、失败重试、空间耗尽及锁定时请求取消等问题。
- **安装与更新**：Windows 系统代理、Linux GNOME/KDE 手动代理及代理环境变量；修复更新助手启动失败、临时目录残留和打包兼容性问题。更新继续验证发行签名、大小及 SHA-256。

## 下载与升级

- **Windows 10/11 x64**：安装版 EXE、绿色 ZIP，包含内置 RDP 标签页测试功能。
- **Linux x64**：DEB、RPM、pacman 和通用 tar.gz；需要 glibc 2.35、GTK3 / WebKitGTK 4.1。
- **macOS 13+**：Apple 芯片与 Intel 通用 DMG / ZIP，仍为未公证的临时签名预览版。
- **Android 7+**：0.3.0，提供 ARM64、ARMv7、x86_64、x86 及通用 APK；沿用原调试签名，可覆盖安装此前 alpha 版本。请保持系统 WebView 更新。
- **源码**：包含桌面、Android、内置 RDP 构建补丁和许可证，不包含用户配置或签名私钥。

桌面版本 **v0.03**，构建 **20261003094**；Linux 包版本 **0.3.0-94**，Android 版本 **0.3.0 / versionCode 9**。Windows、Debian/Ubuntu 与 R28 起的 pacman 客户端可通过“检查更新”升级；新旧域名更新入口均保留。RPM、Linux 通用包、macOS 和 Android 请手动安装新版。RDP 暂仅在 Windows x64 提供。

升级保留配置、密钥、字体和背景。更新前保存正在编辑的文件，桌面更新安装时会关闭连接会话。多实例共用配置时，如另一实例更改安全锁设置，旧实例会要求重启后再解锁或保存。
