# DengShell R20 → R30 更新日志

## 新增功能

- 服务器管理改为目录与连接分栏，多级目录清晰区分；支持整行选中、全局搜索、路径导航、子分组筛选、栏宽保存及右键管理。

- 支持从 FinalShell 导入连接、解析登录密码，支持从 key 文件夹自动导入私钥到密钥管理器并批量关联连接，重复导入补齐缺失关联。
- 命令及命令分组支持拖动排序，编辑操作移入右键菜单。
- 新增长命令编辑区、五个动态参数及发送预览，每条命令可选择是否追加回车。
- 支持跨服务器多文件、多窗口编辑，各窗口拥有独立标签栏，标注所属服务器、当前文件及未保存状态。
- 内置五套简体／繁体中文与英文字体，支持导入字体（重启后生效）和独立设置明暗主题的文字颜色。
- 新增 Arch Linux pacman 安装包和软件内自动更新，更新包含发行签名和防回退校验。

## Bug 修复

- 修复 Windows 自动更新将压缩 EXE 误判为“不是有效 Windows 程序”的问题。
- 修复 Windows 更新完成后主窗口隐藏在托盘；重启后直接显示窗口，保留用户的最小化设置。
- 缺失私钥改为连接时提示重新配置，避免导入后逐个补充密钥。
- 修复最小化选项弹窗的按钮错位、复选框与文字分行。
- 修复浅色模式文字对比度不足。
- 修复 Bash／Zsh／Fish 兼容问题，以及部分环境中系统、磁盘、进程和常用应用检查结果不完整。
- 修复快捷命令意外执行、切换服务器后命令误发及排序保存异常。
- 修复多文件编辑的内容覆盖、跨服务器保存串写，以及保存过程中新增文字丢失。

## 自动更新方式

**Windows、Debian／Ubuntu、Arch pacman：** 重启 DengShell，发现新版本后点击“下载并安装更新”，程序会自动下载、校验、安装并重启，保留原配置。Linux 需要系统安装授权；更新前请保存文件，SSH 连接会断开。

**RPM 和通用 Linux 版：** 下载对应安装包升级，保留原数据目录。

Windows／DEB 的 R20 及后续版本可直接升级至 R30。R28 起的 Arch pacman 版可直接更新；更早的 Arch 版先手动安装一次 R30。此功能不添加 pacman 仓库，`pacman -Syu` 不会从官网获取 DengShell 更新。官网必须同步部署配套升级文件，仅发布 GitHub Release 不会启用官网更新。
