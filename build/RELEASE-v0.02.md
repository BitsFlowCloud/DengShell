## 服务器管理与文件操作

- **服务器备注（#18）**：新建、编辑及快速连接保存均可填写备注；支持搜索、完整查看、复制，随加密配置备份和自建同步保留，FinalShell 导入读取已有描述。列表中备注单独成框，标题独占一行，正文最多三行；每行最多 20 个中文或 40 个英文字符，混排按宽度计算。已有长备注保留完整内容。
- **历史路径搜索（#19）**：快速搜索并打开访问过的目录和文本文件，支持键盘选择、关键词高亮及清空；按服务器与连接身份隔离，每个身份保留最近 200 条，记录不进入云端同步。
- **路径历史删除修复**：永久删除连接后，迟到的 SFTP 请求不能再恢复已删除的历史。临时快速连接在保存前不持久化访问路径。
- **服务器列表**：服务器名加粗、名称与地址靠近；分组树取消“几级目录”标签，优化明暗模式的层次和选中状态。
- **磁盘区域**：已用/可用空间并排并以颜色区分，总空间居中显示，下方保留读取和写入速度；IPv4/IPv6 使用紧凑标签。

## 连接、终端与工作区

- 修复快速连接保存中的窗口竞态：关闭后改为保存另一台服务器，旧请求的成功或失败结果不再关闭或污染新窗口。
- 快速连接支持 SSH 命令、用户@地址和 IPv6；连接成功后可保存，支持密码、托管私钥和 SSH Agent；本机支持 ping 探测。
- SSH 标签从终端左边框开始排列，每行最多六个，窄窗口提前换行；按名称自适应宽度，精简顶栏并统一连接按钮尺寸和文字。
- Ctrl+C 自动回到终端最新输出；直接粘贴多行命令到空闲 SSH 终端时自动执行，保留 heredoc、换行及中文；单行粘贴、命令编辑区和运行中的程序保持原方式。
- 传输任务支持清理已完成记录，SFTP 面板可隐藏和恢复；参数化快捷命令使用紧凑填写界面。
- FinalShell 导入兼容缺失代理引用的连接，提示补配或确认直连；仅导入导出文件实际包含的数据。

## 安全锁、自建同步与平台

- 修复锁定状态下退出确认闪现、关闭按钮无反应的问题（#16、#17）；确认、取消、重试与解锁窗口之间保持正确状态。
- 自建加密同步支持本机、NAS 或 VPS：无需域名，通过包含证书身份的一次性邀请配对；默认同步服务器、分组及快捷命令，可选择同步保存的密码和托管私钥；保留离线编辑、历史恢复、设备撤销和恢复码。
- 修复同步并发合并、失败重试、代理差异引起的重复上传、锁定时取消请求与清理密钥、历史存储空间耗尽、缓慢配对、证书身份与迟到恢复码等问题。仅保留自建同步。
- 提供 Windows x64 安装版和绿色版、Linux x64 DEB/RPM/pacman/通用包、macOS Apple 芯片与 Intel 通用 DMG/ZIP。

## 安装与升级

Windows、Debian/Ubuntu 和 R28 起的 Arch pacman 客户端可通过现有更新地址检查并升级至 v0.02。内部构建号继续递增，发行签名、大小与 SHA-256 校验继续保留。升级保留原配置；更新前保存未提交的编辑内容，更新时会关闭 SSH 会话。

RPM、通用 Linux 包和 macOS 当前需要手动更新。macOS 最低版本为 13，仍为未公证的临时签名预览版。Linux 使用 GTK3/WebKitGTK 4.1，基线为 glibc 2.35。
