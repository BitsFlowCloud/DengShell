# DengShell R40 功能复核

本次全部平台构建号：**20260915041**。发行名称保持 R40，累计更新范围为 R30～R40。

## 已确认并修复

- 用户诊断记录 `7aeedb1ea023` 显示：后台命令超时后约 250 毫秒，客户端主动关闭了 SSH；此时最后成功心跳距关闭仅约 26 毫秒。DS-231 属于客户端误断开，不能据此认定服务器或链路故障。
- 移除进程采集的逐进程 `smaps_rollup` 内存页统计，改为轻量 `/proc/PID/stat` 计数。后端计算 CPU / 内存前五，前端常驻显示五行；CPU 按同一 PID 与启动时间的相邻采样计算，RSS 标明估算。失败保留已标记的缓存并退避重试。
- 系统、进程、网速和其他后台命令各自拥有有界通道。取消与清理失败只影响对应任务；同类任务清理未完成时不会继续堆积，不再用 DS-230/231 主动关闭主 SSH。
- 心跳观察实际 SSH 收包：仅单次心跳回复延迟不会关闭仍有终端、文件或其他 SSH 数据的连接。连续 90 秒没有收包才触发超时；服务器主动关闭、底层传输错误、终端退出或用户关闭仍会正常结束会话。
- 文件操作清理失败仅关闭本连接的 SFTP 通道，SSH 终端继续使用。未完成写入不自动重放；文件通道损坏后需重新连接才能恢复文件管理。
- 重连保留终端文字与颜色，失败后重试也不清空；命令历史继续保存。诊断日志限制大小，不记录命令、口令与密钥，并阻止应用关闭后的迟到回调重新写文件。
- 网速图及后台历史窗口均为 60 秒，保留真实采样断点，不把缺测填成零。
- 两类字体设置统一尺寸和布局，入口文字均为“在线字体”；颜色立即预览并保存，在线字体使用实际字形预览且支持加粗。预览仅加载小型字形子集，完整字体经确认后下载。手动导入界面字体仍按原约定重启后启用。

## 验证边界

本轮使用独立配置和本机 SSH 故障环境，未读取或修改用户 VPS 数据。没有复现用户所在的实际丢包网络；测试能证明已处理的误断开路径，不能保证任意网络永不掉线。原生 Linux 容器不能覆盖全部实体桌面的显卡、Wayland、托盘和 polkit 组合；Windows 运行器也不等于所有 Windows 10/11 设备。

轻量 RSS 与精确页统计的取舍参见 [Linux /proc 文档](https://docs.kernel.org/filesystems/proc.html)。
