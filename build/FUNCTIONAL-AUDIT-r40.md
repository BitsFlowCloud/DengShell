# DengShell R40 功能复核与发布验证

构建号：20260914040。更新范围为 R30～R40。

## 功能复核

- Go 全量测试：526 个测试及子测试通过；36 个依赖平台或显式隔离环境的测试跳过，不计入通过数。另行执行的环境测试见下文。`go vet ./...` 通过。
- 前端 15 组回归通过，覆盖命令历史、提示符、曲线、终端快照、字体、分组树和编辑器。修复浏览器退出后清理临时目录的时序竞争，功能断言通过。
- 独立 SSH 容器中 Bash、Zsh、Fish 全部通过：SSH/SFTP、系统监控、应用检查、启动配置、命令历史、忙碌与 Ctrl+C、原始提示符及颜色恢复。未连接或修改真实用户服务器。
- 分组子树删除包含全部后代及其连接，必须三次确认并输入名称；目录内容变更后拒绝旧确认。删除清理连接历史及网卡布局，晚到事件不能重新写回已删除数据。全局历史与共享密钥保持各自语义。
- 四级分组背景色、选中样式、收窄连接列表，以及多个服务器的独立编辑器标签均有浏览器交互回归；编辑器测试使用专用虚拟文件，不读写用户文件。
- 内置界面字体为 IBM Plex Sans SC，Shell 字体五套；在线目录为 20 款界面字体和 30 款 Shell 字体。下载验证固定来源、大小、SHA-256 与字体格式，保留许可、取消和离线复用；慢加载不会覆盖用户后来的选择。

## 发行验证方式

Linux 以 Ubuntu 22.04 / glibc 2.35 构建。在 Ubuntu 22.04、Ubuntu 24.04、Debian 12、Fedora 43、openSUSE Tumbleweed、Arch Linux 六个隔离容器中实际启动 GTK/WebKit 原生界面，全部通过。精确可执行文件哈希与运行环境见 [COMPATIBILITY.json](linux/COMPATIBILITY.json)。

发行流程还检查安装与卸载保留配置、旧 DEB / pacman 更新助手安装本次文件及重新打开窗口、更新签名、归档内容和嵌入资源一致性。Windows ZIP、NSIS 安装器和升级后主窗口的实际验证记录发布在仓库的 **Windows release validation** Actions 中，所测文件以 SHA-256 对应本次发行附件。

GitHub 附件仅包含 Windows 安装版及绿色 ZIP、Linux DEB / RPM / pacman / 通用包和源码 ZIP。官网同时发布三个平台的固定路径更新文件与签名清单；发布前必须校验三组二进制与清单匹配，发布后重新读取公网文件核对。

## 验证边界

Linux 为 X11 / 软件渲染容器，不能代表所有实体显卡、Wayland、托盘、缩放和桌面 polkit 授权代理。Windows 验证在 GitHub Windows 运行器进行，不能代表每台 Windows 10 / 11 实体电脑或所有安全软件。没有生成或声称验证 macOS、ARM、32 位或 musl 客户端。测试只使用独立配置及临时 SSH 密钥，不覆盖实际用户数据。

更详细的修复背景见 [功能复核](FUNCTIONAL-RECHECK-20260914.md) 和 [字体改革](FONT-REFORM-REPORT.md)。
