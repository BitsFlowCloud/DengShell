# DengShell R40 功能复核

本次全部平台构建号：**20260915042**。发行名称保持 R40，累计更新范围为 R30～R40。

## 已确认并修复

- 用户诊断记录 `7aeedb1ea023` 显示：后台命令超时后约 250 毫秒，客户端主动关闭了 SSH；此时最后成功心跳距关闭仅约 26 毫秒。DS-231 属于客户端误断开，不能据此认定服务器或链路故障。
- 进程先以轻量 `/proc/PID/stat` 筛选 CPU / 内存前五候选，再独立精读候选的 `smaps_rollup` RSS（旧内核回退 `smaps`）。两个列表合计最多十个 PID；显示值只来自精读，不回退估算。校验启动标识及 PID 启动时间，避免 PID 复用；逐条保留完整结果，六秒预算后退避，不阻塞主监控。排名基于候选筛选，并非全机同一时刻的精确内存快照。
- 系统、进程、网速和其他后台命令各自拥有有界通道。取消与清理失败只影响对应任务；同类任务清理未完成时不会继续堆积，不再用 DS-230/231 主动关闭主 SSH。
- 心跳观察实际 SSH 收包：仅单次心跳回复延迟不会关闭仍有终端、文件或其他 SSH 数据的连接。连续 90 秒没有收包才触发超时；服务器主动关闭、底层传输错误、终端退出或用户关闭仍会正常结束会话。
- 文件操作清理失败仅关闭本连接的 SFTP 通道，SSH 终端继续使用。未完成写入不自动重放；文件通道损坏后需重新连接才能恢复文件管理。
- 重连保留终端文字与颜色，失败后重试也不清空；命令历史继续保存。诊断日志限制大小，不记录命令、口令与密钥，并阻止应用关闭后的迟到回调重新写文件。
- 网速图及后台历史窗口均为 60 秒。将独立采样超时从三秒调整为十秒；有完整计数依据的延迟样本允许最多十五秒实际间隔，按该间隔计算平均速度并明确说明。真正失败、计数重置与长时间暂停仍保留缺口。
- 两类字体设置统一尺寸，字体卡片改为两行，居中入口均为“在线字体”，重复说明删除；颜色立即预览并保存，在线字体使用实际字形预览且支持加粗。预览仅加载小型字形子集，完整字体经确认后下载。手动导入界面字体仍按原约定重启后启用。

- 修复模态背景遮挡或模糊提示：通知归属于当前最上层模态窗口，并在支持时使用浏览器顶层显示；旧版回退不丢提示、不夺输入焦点。

## 安装包与更新验证

Windows 原生界面、安装／卸载及更新重启由仓库 `Windows release validation` 工作流验证；以本构建对应的 Actions 结果和附件 SHA-256 为准。Linux 使用 Ubuntu 22.04 / glibc 2.35 构建，验证矩阵见 [COMPATIBILITY.json](linux/COMPATIBILITY.json)，包括 Ubuntu 22.04/24.04、Debian 12、Fedora、openSUSE 和 Arch 的原生启动与包管理器安装／卸载。

同名 R40 使用更高内部构建号，Windows / DEB / pacman 的更新清单继续使用原发行密钥签名。Linux 包内部修订号为 `42`（仍为 R40 发行，兼容旧 pacman 更新器的构建号校验），使包管理器能区分本次替换版本与旧 R40；RPM 与通用包沿用手动安装方式。

GitHub 仅保留 Windows 安装版、绿色 ZIP、Linux DEB/RPM/pacman/通用包和源码 ZIP。发布后核对官网安装文件、三个更新入口与签名清单。

## 验证边界

本轮使用独立配置和本机 SSH 故障环境，未读取或修改用户 VPS 数据。没有复现用户所在的实际丢包网络；测试能证明已处理的误断开路径，不能保证任意网络永不掉线。原生 Linux 容器不能覆盖全部实体桌面的显卡、Wayland、托盘和 polkit 组合；Windows 运行器也不等于所有 Windows 10/11 设备。

轻量 RSS 与精确页统计的取舍参见 [Linux /proc 文档](https://docs.kernel.org/filesystems/proc.html)。
