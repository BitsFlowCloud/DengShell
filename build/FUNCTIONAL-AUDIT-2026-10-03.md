## 已修复的功能问题

| 优先级 | 问题与触发条件 | 修复及回归证据 |
| --- | --- | --- |
| 高 | 远程项目名为 `~` 时，删除、重命名、打开、下载或目录上传可能把它展开为主目录，操作错误目标。 | 普通路径按字面解析，仅显式导航展开所属会话的 home。单元回归及真实 SFTP 浏览器测试验证 `~` 文件/目录操作，主目录哨兵文件保持不变。 |
| 高 | 下载或打开 FIFO、设备等特殊文件时，先 OPEN 后检查可能卡住文件通道；原生下载可能覆盖已有本地文件。 | 读取前 STAT 检查普通文件，打开后再次 FSTAT 检查。覆盖 FIFO、设备、目录、打开期间类型变化、正常文件及符号链接；失败不生成或覆盖本地目标。 |
| 高 | 旧实例保存安全锁状态时，可覆盖另一实例的新设置；锁文件损坏/删除或密钥改变后仍可继续覆盖；TOTP 可跨实例重放。 | 使用目录文件锁、密钥校验及磁盘摘要比较，原子写入成功后才更新内存状态。异常时拒绝覆盖和解锁，保留文件。新增多实例、损坏、删除、密钥变化和 TOTP 重放回归。 |
| 中 | 默认不传秘密的同步中，远端改变认证方式后，本机仍可能把私钥口令当登录密码使用，或留下过时私钥路径。 | 仅在协议和认证方式兼容时保留本机凭据。覆盖 password/key/agent 转换、共享秘密模式及正常凭据保留。 |
| 中 | 快速切换目录时，旧请求失败会覆盖新目录的正常状态；关闭或替换会话后的迟到响应仍可能回写。 | 导航成功和失败均校验请求代次、连接状态及会话对象身份。覆盖过期失败、断开、关闭、替换和跨会话 home。 |
| 中 | 文件操作超时关闭 SFTP bridge 后，接口仍把已关闭的文件通道报告为可用。 | 原子记录 bridge 关闭状态，不再返回失效通道；验证文件状态正确，SSH 终端和命令不受影响。 |
| 中 | 批量上传允许覆盖时，其中的新文件也要求 OpenSSH PosixRename 扩展，普通 SFTP v3 服务会上传失败。 | 仅替换已有文件使用原子覆盖扩展；新文件使用标准 Rename。真实 SFTP v3 协议 fixture 验证成功及原文件保护。 |
| 中 | 一个会话的延迟请求未完成时，会阻止其他会话刷新延迟；隐藏/锁定窗口仍继续轮询，迟到结果可能写回失效会话。 | 按会话限制并发请求，遵循可见性和锁定状态，忽略断开/替换后的响应。新增慢会话、切换、锁定和迟到响应回归。 |
| 中 | 桌面窗口交接、恢复或连接失效期间，命令发送被拒绝，输入框仍被清空，丢失尚未发送的草稿。 | 只有发送成功才清空输入，与 Android 既有保护一致。覆盖六种不可发送状态及成功发送。 |

以上修改均补充了有针对性的回归测试。共用 Go 后端和前端修改已同步至 `android/internal/app` 与 `android/mobile/assets/web/app.js`；没有生成 APK。

## 测试与文档维护

- 修正密钥口令测试中过时的连接调用和测试替身。
- 根据已有更新日志修正两项旧断言：参数命令目标跟随当前标签；重复点击当前服务器分组会折叠。README 和命令使用说明同步修正。
- 持续后台轮询使 `networkidle0` 偶发永不达成。受影响的上传提醒、同步、安全锁、RDP 和标签拖动测试改为等待明确的应用就绪状态，保留功能断言。
- 标签拖动回归等待布局稳定、目标滚入可见区并检查鼠标命中，避免测试误拖其他标签。
