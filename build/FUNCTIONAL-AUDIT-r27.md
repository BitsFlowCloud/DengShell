# DengShell R27 修复与验证

日期：2026-09-14。构建号：`20260914027`。

## 修复原因与范围

最小化弹窗使用了通用 dialog 标签、输入框和 primary-button 样式。通用样式让标签纵向排列、输入框与主按钮宽度为 100%，造成复选框独占一行、“隐藏到托盘”挤到下一行。

本次只为该弹窗明确复选框尺寸、标签横向排列、按钮宽度与高度；给标签文字增加独立 span。取消、最小化、托盘、记住选择和托盘不可用时的行为保持原有逻辑。

## 验证

实际 Chromium 加载全部应用 CSS 和原始托盘脚本：浅色／深色、100%／125%／150%／200% 缩放、360 像素窄窗口；复选框与文字对齐，三个按钮正常同排且等高，窄窗口无横向溢出。取消、普通最小化、托盘、记住／不记住及托盘不可用的交互验证通过。此项原生桥由独立测试替身接收调用。

R26 的 469 项 Go 测试、17 个前端回归及其他功能审查是上一版记录，详见 [R26 功能审查](FUNCTIONAL-AUDIT-r26.md)，本次未把旧测试重命名为 R27 全量测试。

最终程序和包的哈希、Linux 启动与安装验证、R20 旧更新器升级验证将随发行附件另行记录。Windows 为交叉编译和静态包检查，尚未执行本次 Windows 实机运行、升级及安装／卸载。

## 边界

没有改动真实用户配置、密钥、字体或背景。Linux 验证在隔离容器中使用 Xvfb／软件渲染，不覆盖全部实体显卡、Wayland 和托盘环境。在线更新需要网站实际部署配套文件并清除固定更新地址的旧缓存，不能仅凭本地验证声称线上已生效。
