# R50 功能复核

## 变更范围

- #16：锁屏期间提供独立退出确认，仅关闭当前窗口拥有的连接；不解锁其他窗口、不绕过受保护接口。
- #14：SSH 标签按名称占用宽度，每行最多六个，窄窗口提前换行。
- #15：已保存命令的参数执行使用紧凑界面；完整模板编辑仍可显式进入，参数发送到原目标标签。
- #7：批量清理仅移除成功完成的传输；保留进行中、失败和取消记录。服务器管理居中、快速连接入口独立，SFTP 区域可隐藏。
- #8：解析有限 SSH 地址语法创建临时连接，连接成功后可主动保存；未保存时不写入服务器列表。无 SSH 会话时支持有限次数的本机 ping。
- #4：FinalShell 连接导入保留缺失代理的条目并阻止未确认的直连；快捷命令按钮紧凑化。文本编辑器现有标签信息和搜索隔离继续回归。用户提供的导出没有快捷命令，因此按用户要求不实现该部分，也不启动 FinalShell。

## 验证

Go 后端与竞态检查、静态检查、JavaScript 语法和命令/编辑器用例；使用隔离配置和 SSH 测试服务验证临时连接保存、锁屏关闭当前窗口并保留另一窗口。浏览器验证标签换行、紧凑参数执行、传输清理、快速入口、锁屏退出及现有安全锁和编辑器回归。

发行包通过同一份冻结程序生成。Windows 在 GitHub Actions 的 Windows Server 2022 验证安装、启动和从旧版本更新；Linux 在六个独立发行版容器验证 GTK3/WebKitGTK 4.1 原生启动及安装/卸载。发布前核对签名、哈希、源码内嵌资源和 R40 更新识别。

## 边界

未使用用户真实服务器进行压力测试，未启动 FinalShell。Windows 自动验证环境不是物理 Windows 11；Linux 使用 X11 软件渲染容器，物理 GPU、Wayland 和托盘体验仍需实际设备验证。RPM 和通用包维持原有手动安装方式，macOS 暂停。
