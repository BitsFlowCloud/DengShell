# DengShell v0.01 R50 累计更新

当前内部构建号：`20260920059`。旧 R40、官网已发布的 R50，以及较早的 R50 测试构建均可识别更高内部构建号。

## 本次修复与新增

- **终端输入**：Ctrl+C 中断时自动回到最新输出；直接粘贴多行命令到空闲 SSH 终端时自动执行，保留 heredoc、换行及中文内容。单行粘贴、命令编辑区和正在运行的程序保持原有输入方式。
- **侧栏更紧凑**：IPv4 / IPv6 改为左上角小标签，地址区域高度约减半；磁盘仅显示已用、可用和总空间，下方保留读写速度。
- **标签对齐**：SSH 标签从终端左边界开始排列，兼容侧栏置右及窄窗口；保留每行最多六个标签。
- **修复无法退出（#17）**：启用安全锁后，焦点恢复检查可能使退出确认闪现后消失，后续点击关闭也无反应。现在确认界面会随锁定状态正确切换；重复关闭可再次触发确认，取消不会退出，退出失败保留错误提示并可重试。保留 #16 的锁定/解锁输入界面直接退出能力。
- **自建加密同步**：安全锁右侧新增独立「同」按钮，间距 14px。可在本机开启服务，或加入 NAS / VPS 上的独立服务；无需域名，通过携带证书身份的一次性邀请配对。默认同步服务器、分组、快捷命令；本机创建空间时可选择同步已保存密码和托管私钥。仅保留自建方式，已移除 Google Drive 接入。
- **同步正确性修复**：修复三设备并发冲突遗漏新版本、写入失败后的重试、设备代理差异导致重复上传、锁定时请求取消和密钥清理、历史占满空间后不能继续同步、缓慢配对阻塞，以及证书身份丢失和迟到恢复码显示等问题。保留历史恢复、离线编辑及设备撤销。
- **macOS 通用预览版**：提供 Apple 芯片和 Intel 通用 DMG / ZIP，最低 macOS 13。使用系统 WebKit 和 Dock；目前为临时签名，未经过 Apple 公证，尚不支持软件内自动更新，更新时退出并替换应用即可保留配置。

## R50 已有功能与界面改进

- 快速连接支持 `用户@主机`、`ssh -p 端口 用户@主机`，连接后可保存；未保存的临时连接不写入服务器列表。支持密码、托管私钥、SSH Agent 和本机 ping 探测（#8）。
- 传输任务可批量清除已完成记录，保留进行中及失败任务；顶部「＋」打开快速连接，SFTP 面板可隐藏/恢复（#7）。
- 参数化快捷命令使用紧凑填写界面，保留明确执行目标和独立编辑入口（#15）。FinalShell 导入允许处理缺失代理引用，但需补配代理或明确确认直连；仅导入实际提供的连接资料（#4）。
- 标签按名称自适应宽度，每行最多 6 个，窄窗口提前换行（#14）；统一快速连接按钮宽高、字号和居中方式，调整按钮间距并移除顶部名称/版本文字。

## R20 至 R40 累计保留

- 多级服务器分组、分组颜色、FinalShell 连接/私钥导入，多会话与独立窗口；文本编辑支持搜索、替换、定位行和跨服务器标签，操作仅作用于当前标签。
- 密码/2FA 安全锁、空闲自动锁定和手动锁定；锁定时模糊并隔离工作界面。
- CPU / 内存前五进程及完整进程页，支持搜索、排序、分页和暂停；网速和延迟显示最近 60 秒。修复监控采集导致 SSH 误断、重连丢失终端显示及采样断点。
- 精简内置字体，独立设置界面和 Shell 字体，提供在线字体库；改善服务器管理、编辑器和多层弹窗布局。
- 更新检查和下载支持 Windows 系统代理、Linux GNOME / KDE 手动代理与代理环境变量；修复更新助手启动失败和临时更新目录残留。

## 安装与更新

提供 Windows x64 安装版/绿色 ZIP，Linux x64 DEB、RPM、pacman、通用 tar.gz，macOS 通用 DMG/ZIP，以及完整源码 ZIP。

Windows、Debian / Ubuntu 和 R28 起的 Arch pacman 版本启动时检查更新，确认后下载、校验、安装并重启。Windows / DEB 的 R20 可直接升级；较早 Arch 版需先手动安装一次。RPM、通用 Linux 包及 macOS 预览版手动更新。

更新前保存正在编辑的文件，升级会关闭 SSH 会话，继续使用原配置目录。R21 起验证发行签名、大小及 SHA-256；R20 升级后获得签名验证能力。同步不能代替离线备份，恢复码应单独妥善保存。
