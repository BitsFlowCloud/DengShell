# DengShell 官网部署与功能复核

日期：2026-09-14。客户端基线：当前 R34 源码及上一轮字体改革。此次直接部署官网字体库增量，同时补齐此前暂停的分组与编辑器需求，并修复复核中确认的功能问题。客户端版本号、EXE、安装包和 GitHub 发行版未更新。

## 结论

官网字体库已上线：[https://ds.free-vps.org/fonts/](https://ds.free-vps.org/fonts/)，首页已有入口。20 款界面字体、30 款 Shell 字体可预览并在确认后下载，含完整字体许可。

已修复两类确认的功能缺陷：永久删除连接后遗留单连接历史状态，以及字体异步加载覆盖用户后选字体。已补齐四项旧需求：任意层级分组连同子连接删除、任意层级背景色、连接列表缩窄、文本编辑器重复信息精简。下述检查未发现尚待修复的确定回归，验证范围外的平台与场景不等同于已通过。

## 已确认问题与处理

| 问题 | 原行为及影响 | 当前处理 | 验证 |
| --- | --- | --- | --- |
| 非空分组无法删除，未满足全部层级删除需求 | 菜单仅允许删除空分组，有子组、连接或回收站连接时按钮禁用 | 新增子树删除接口与三次确认，最后准确输入分组名称；展示组数、正常连接和回收站连接数量 | 浏览器分别取消第 1/2/3 次确认、名称错误、最终删除；Go 子树范围与持久化测试 |
| 删除确认期间目录可能变化 | 单纯三次弹窗不能保证最终删除范围仍与提示一致 | 为整个子树及连接配置计算修订指纹，提交时在锁内重算；新增、移动或修改连接/分组会要求重新确认 | 确认期间增加子组、修改凭据均拒绝删除，保留全部原数据 |
| 永久删除后单连接历史遗留 | 原 Purge 仅清理连接配置与连接记录，历史布局和内存状态仍允许迟到请求继续写入 | 清理该连接的终端历史、网卡偏好及历史状态；子树删除与连接注册/历史提交串行检查；相关会话并行断开 | 写入失败完整回滚、晚到连接无法重新注册、晚到历史不能复活、重开配置后保持删除 |
| 分组未支持背景色 | 分组数据无背景色字段 | 所有层级新增六位 HEX 颜色并持久化；自动匹配黑/白文字；选中后以边框及勾选标记突出；可恢复跟随主题 | 四级目录逐级显示、明暗主题、编辑并保存；无效颜色拒绝 |
| 连接管理右侧列表过宽 | 窗口最大宽度 820 CSS px | 最大宽度收为 700 CSS px，默认目录栏仍为 320 px；保留拖动分栏、深层横向滚动与缩放适配 | 浏览器测量宽度、目录筛选和 1,200 层遍历回归 |
| 文本编辑器重复显示服务器和文件路径 | 标题、文件标签、归属说明重复显示 | 标题统一为“文本编辑器”；标签保留服务器、文件名与当前查看；完整路径单独显示一次，完整连接地址放入悬浮提示 | 两台模拟服务器同名配置文件独立内容；移入独立窗口后各有标签栏；保存目标与并发编辑模型回归 |
| 较慢字体加载覆盖后选字体 | 先选 A，A 仍在加载时选 B，A 完成后仍保存为当前字体；下载完成的检查也早于最终 FontFace 加载 | 字体选择增加请求序号；加载完后再次检查选择意图与取消状态；同字体重复点击不会排队重复确认 | 新回归先在修复前复现失败，修复后通过；浏览器下载、取消及当前/另一窗口新选择保护通过 |

删除范围是本机该子树内的连接配置、保存于连接中的凭据、连接记录及单连接终端历史/网卡偏好。全局命令历史按此前需求继续保留；密钥管理器、代理、自定义字体/背景以及远程文件不删除。未保存文本草稿继续可见和可复制。原有配置备份机制保持不变，因此“永久删除”指从当前配置与回收站移除，不是抹除备份。

旧版“删除空分组”后端接口继续保留兼容性；新版界面的子树删除使用专用接口。三次确认是防误操作流程，不是替代本地 API 身份认证的安全边界。
