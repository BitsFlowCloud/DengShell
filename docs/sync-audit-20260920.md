## 已修复的问题

| 问题 | 修复与回归验证 |
| --- | --- |
| 三台及以上设备并发修改时，冲突选项可能遗漏新版本，或仍显示已经解决的旧版本 | 先收集所有设备仍有效的版本，再形成冲突选项；验证三台真实客户端并发、六种合并顺序以及冲突解决后的收敛。 |
| 历史记录等网络请求未参与取消，安全锁可能等待网络超时才清除同步密钥 | 统一同步操作的取消和锁定检查；锁定后取消请求并清除密钥，返回敏感数据前再次检查锁定状态。 |
| 本地同步日志保存失败后，重试可能直接上传未持久化的操作 | 记录未完成的保存，任何后续远程操作前必须先保存；模拟连续写入失败，确认零上传，解除故障后仅上传一次。 |
| 同一密文携带不同序号重试时，服务端可能误报成功 | 同时校验密文、设备身份和序号，身份变化返回冲突。 |
| 历史快照耗尽容量后，即使可清理历史也无法继续上传 | 在同一数据库事务内写入和清理，保留每台设备最新快照；容量仍不足则整体回滚。 |
| 未认证的缓慢配对请求持有全局锁，阻塞正常设备 | 在取得共享状态锁前限量读取请求正文；短请求设置读取期限，上传在读取前后检查授权。 |
| 丢失证书身份文件可能静默生成新身份；根证书临近到期时反复签发叶证书 | 已有数据库缺失身份文件时拒绝启动；在有效期内复用正确证书，到期明确失败。 |
| 各设备保留不同本机代理配置后可能重复上传 | 用实际落地配置建立本机比较基线，保留设备本地代理，同时避免无变化上传。 |
| 仅下载合并时没有检查合并后的总量限制 | 应用前检查总记录数、时钟设备数和快照大小；两个分别合法但合计超限的快照不会改写本机配置。 |
| 同步窗口关闭后，迟到的恢复码响应可能重新填入隐藏输入框 | 响应到达时复查窗口和锁定状态；浏览器测试模拟迟到响应。 |
