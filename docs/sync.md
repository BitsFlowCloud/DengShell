# DengShell 加密同步

点击安全锁右侧的「同」按钮。两者间隔 14 CSS px，安全锁仍独立使用。

## 选择方式

- **本机 / 自建服务**：数据存放在自己的电脑或 NAS。局域网内直接连接；跨网络需要已有的安全网络连接及可达 IP。

每台设备一次只连接一个同步空间。更换服务前使用「断开连接」；本机连接配置与原空间数据保留。

默认同步服务器、服务器分组、快捷命令和命令分组。创建空间时可选择同时同步已保存的 SSH 密码与**托管**私钥。代理配置、外部私钥路径、历史记录、字体/背景、安全锁和本机排列顺序留在设备本地。同步来的代理连接需要在新设备配置对应代理。

同步口令至少 12 个字符，建议使用密码管理器生成。它独立于安全锁密码。恢复码可解密同步密文，请保存在其他安全位置；恢复码本身不是数据备份。

## 本机开启：最少步骤

1. 「同」→「本机 / 自建服务」→「在本机开启 / 恢复同步服务」。选择本机局域网 IP，填写设备名称和同步口令，点击连接。只在同一台电脑测试时可选 `127.0.0.1`。
2. 保存恢复码，点击「邀请其他设备」。把完整邀请通过可信渠道传给另一台自己的设备。
3. 另一台设备选择「加入已有同步服务」，粘贴邀请，输入同一个同步口令。

邀请 10 分钟有效、一次使用；输错同步口令不会消耗邀请。允许最多 32 台授权设备，管理设备可撤销其他设备。Windows 如弹出防火墙提示，请按实际使用的可信网络放行 DengShell 对应的同步端口（默认 TCP 18443）。

服务随 DengShell 启动。**退出软件、电脑休眠或关闭服务后，其他设备暂时不能同步。**配置仍可离线编辑。需要全天在线时，使用下面的独立服务。

无需域名，无需把证书安装到系统信任库。邀请中携带专属于该服务的证书身份，客户端仅在该连接中信任它；服务器使用 5 年根身份和自动轮换的 90 天 IP 证书。根身份到期或需要更换 IP 时需要重新配置/配对，不会自动忽略证书错误。

### 独立服务（NAS / Linux / VPS，可选）

已有 Go 1.26 环境时，在源码目录编译：

```sh
go build -buildvcs=false -o dengshell-sync ./cmd/dengshell-sync
./dengshell-sync --ip 192.168.1.10 --port 18443 --data ./sync-data
```

`--ip` 是客户端访问的真实 IP；`--listen` 可另设监听地址。默认只监听 `--ip`，不暴露终端、SFTP 或 DengShell 本机控制接口。首次启动终端会显示一次性初始化连接资料，在客户端选择「加入已有同步服务」完成初始化。独立服务首次初始化默认不包含密码和私钥。

Docker 方式，在项目根目录执行：

```sh
docker build -f build/sync/Dockerfile -t dengshell-sync .
sudo install -d -m 700 -o 65532 -g 65532 ./sync-data
docker run -d --name dengshell-sync --restart unless-stopped \
  --read-only --cap-drop ALL --security-opt no-new-privileges \
  -p 18443:18443 -v "$PWD/sync-data:/data" dengshell-sync \
  --ip 192.168.1.10 --listen 0.0.0.0 --port 18443 --data /data
docker logs dengshell-sync
```

把示例 IP 换成自己的可达 IP。初始化资料属于管理凭据，不公开日志。备份时停止服务后复制整个 `sync-data` 目录，再重新启动，保留 `identity.pem` 和数据库。不要只复制运行中的 `sync.db`，SQLite 可能还有尚未合并的 WAL 文件。

本机集成模式丢失管理设备凭据时，可断开旧同步配置，重新选择「在本机开启 / 恢复」，输入原口令或恢复码。恢复成功会撤销旧管理设备凭据；已有同步密文仍保留。独立服务管理员凭据丢失时，请先保留完整目录与客户端加密凭据备份；当前界面不提供远程重置管理权限。

## 同步、冲突与恢复

- 解锁后约每 30 秒检查一次；也可手动「立即同步」。退出或安全锁定会清除内存中的同步解密密钥，重新使用时输入本设备同步口令。
- 不同记录自动合并；同一记录的并发修改或删除由用户选择保留的版本。不会用电脑时间决定哪一条覆盖另一条。
- 两台设备独立创建的同名分组会保留，重复名称增加短编号，保留各自连接。全新安装的空默认分组不会重复导入。
- 每台设备保留最近 20 次上传；「历史版本」可恢复为一次新修改。同步覆盖前另保留最近 10 份本机加密配置备份，位于 `data/sync-backups`。恢复范围仅限参与同步的内容。
- 单次加密快照上限 16 MiB，自建服务密文容量上限 256 MiB。达到容量限制会报错停止，不会静默截断。
- 检测到之前见过的云端版本缺失、回退、内容损坏、空间身份变化，或同一设备配置被复制后并发写入时，会停止同步。不要复制已配对的 `dengshell.sync.enc` 当作新增设备，应重新加入空间。
- 断开连接会保留原加密凭据备份和原空间数据；不会自动撤销 自建服务上该设备的访问。设备遗失时在管理设备中撤销授权。
- 撤销授权不能收回已经下载的明文或密钥。怀疑设备泄露时，应新建同步空间、使用新口令，并另行更换可能泄露的 SSH 凭据。

同步不替代离线备份。存储端仍能看到数据大小、上传时间、随机设备编号（自建端也保存设备名）；快照内容、SSH 密码和私钥在客户端加密。
